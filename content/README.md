# 最新動態 內容發佈說明

網站的「最新動態」內容就放在這個資料夾，**一篇文章 = 一個 `.md` 檔**，放進 `content/posts/` 就會出現在網站上。

## 沒有文章的時候
- 首頁**不會**出現「最新動態」區塊，導覽列也不會有這個連結。
- 直接開 `/news/` 會看到一個「新品與文章，即將與你見面」的空狀態頁，引導訪客去看產品或預約諮詢。
- 放進第一篇文章後，首頁區塊和導覽列連結會**自動出現**，不用改程式。

## 新增一篇文章
在 `content/posts/` 新增檔案，檔名用英文、數字、連字號，例如 `2026-11-20-winter-oil.md`：

```
---
title: 冬季平衡身體油上市
date: 2026-11-20
type: 新品
summary: 一句話簡介，會顯示在卡片上
cover: /images/posts/winter-oil.jpg
---

這裡開始寫內文，可以用 Markdown：

## 小標題

一般段落、**粗體**、[連結](https://example.com)、圖片 ![說明](/images/posts/xxx.jpg)。
```

- `type`：`新品` 或 `文章`（其他字也可以）
- `cover`：封面圖，可省略。圖片放在 `public/images/posts/`
- `draft: true`：加上這行代表草稿，不會發佈
- 檔名開頭是 `_` 的檔案會被忽略

新增或修改後，建置時會自動轉換（`npm run build` 前會自動執行；本機想立刻看到可執行 `npm run content`）。
